# Ana Carolina Santos

**Quality Engineering | AI Engineering | Test Automation | Software Architecture**

Tenho experiência em QA desde 2010, com uma trajetória que conecta automação de testes, qualidade de software e arquitetura. Minha trajetória está evoluindo para AI Engineering aplicada à Quality Engineering. Meus interesses atuais incluem avaliação de LLMs, RAG, context engineering, sistemas multiagentes e governança de autonomia.

> Os tópicos de AI Engineering são áreas de atuação e exploração em andamento. Esta página não os apresenta como projetos concluídos.
