# Public projects

Public repositories with examples of test automation, API testing, and study materials.

## Web and end-to-end automation

- [testes-e2e-com-cypress](https://github.com/AnaCarolinaSantos-qa/testes-e2e-com-cypress) — Cypress scenarios for sign-up, login, sessions, and CRUD.
- [CypressCucumber](https://github.com/AnaCarolinaSantos-qa/CypressCucumber) — Cypress/Cucumber automation for a local form.
- [cypress_boilerplate](https://github.com/AnaCarolinaSantos-qa/cypress_boilerplate) — a starter structure for Cypress automation.
- [robot_framework_qa_starter](https://github.com/AnaCarolinaSantos-qa/robot_framework_qa_starter) — an automation lab with API, UI, mobile, accessibility, and performance examples.

## API testing and applications

- [Testes_API_NodeJS](https://github.com/AnaCarolinaSantos-qa/Testes_API_NodeJS) — API testing exercises with Node.js, Mocha, Chai, and Supertest.
- [zapLink](https://github.com/AnaCarolinaSantos-qa/zapLink) — a virtual service-booking app with Vue.js, Node.js, and MongoDB, including API tests.
- [API_Restful_Sinatra](https://github.com/AnaCarolinaSantos-qa/API_Restful_Sinatra) — a Sinatra API with RSpec and MongoDB tests.
- [rocklov](https://github.com/AnaCarolinaSantos-qa/rocklov) — a course project with API and web scenarios using Ruby, RSpec, and Cucumber.

## Study materials

- [NinjaWeek](https://github.com/AnaCarolinaSantos-qa/NinjaWeek) — QA study materials and exercises.
- [RobotFrameworkWeek](https://github.com/AnaCarolinaSantos-qa/RobotFrameworkWeek) — Robot Framework study materials and examples.
