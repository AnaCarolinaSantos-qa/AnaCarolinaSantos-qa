# Catálogo de projetos

Este catálogo aponta para repositórios públicos originais. O perfil não replica seus arquivos. A seleção destaca exemplos representativos e não é uma classificação de qualidade ou maturidade.

## Destaque

- [robot_framework_qa_starter](https://github.com/AnaCarolinaSantos-qa/robot_framework_qa_starter) — auditoria estática registrada em [Estratégia do portfólio](../docs/portfolio-strategy.md#auditoria-do-candidato-principal). É uma estrutura experimental em evolução; os testes de API/UI atuais são demonstrações `Hello World` e não há execuções recentes verificáveis de CI.

## Outros exemplos

- [testes-e2e-com-cypress](https://github.com/AnaCarolinaSantos-qa/testes-e2e-com-cypress) — exemplo de automação end-to-end em Cypress com documentação de execução local e em CI.
- [Testes_API_NodeJS](https://github.com/AnaCarolinaSantos-qa/Testes_API_NodeJS) — exercícios de automação de API com Node.js, Mocha, Chai e Supertest.
- [rocklov](https://github.com/AnaCarolinaSantos-qa/rocklov) — projeto de curso com cenários de API e web em Ruby/RSpec e Cucumber.
- [cypress_boilerplate](https://github.com/AnaCarolinaSantos-qa/cypress_boilerplate) — boilerplate e configuração de CI para Cypress.
- [zapLink](https://github.com/AnaCarolinaSantos-qa/zapLink) — aplicação de agenda virtual com Vue.js, Node.js e MongoDB.
- [CypressCucumber](https://github.com/AnaCarolinaSantos-qa/CypressCucumber) — automação de formulário com Cypress e Cucumber.
