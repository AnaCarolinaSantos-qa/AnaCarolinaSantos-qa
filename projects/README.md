# Projetos públicos

Repositórios públicos com exemplos de automação, testes de API e materiais de estudo.

## Automação web e ponta a ponta

- [testes-e2e-com-cypress](https://github.com/AnaCarolinaSantos-qa/testes-e2e-com-cypress) — cenários Cypress de cadastro, login, sessão e CRUD.
- [CypressCucumber](https://github.com/AnaCarolinaSantos-qa/CypressCucumber) — automação Cypress/Cucumber de formulário local.
- [cypress_boilerplate](https://github.com/AnaCarolinaSantos-qa/cypress_boilerplate) — estrutura inicial para automação com Cypress.
- [robot_framework_qa_starter](https://github.com/AnaCarolinaSantos-qa/robot_framework_qa_starter) — laboratório com exemplos de API, UI, mobile, acessibilidade e performance.

## Testes de API e aplicações

- [Testes_API_NodeJS](https://github.com/AnaCarolinaSantos-qa/Testes_API_NodeJS) — exercícios de API com Node.js, Mocha, Chai e Supertest.
- [zapLink](https://github.com/AnaCarolinaSantos-qa/zapLink) — aplicação de agenda virtual com Vue.js, Node.js e MongoDB, incluindo testes de API.
- [API_Restful_Sinatra](https://github.com/AnaCarolinaSantos-qa/API_Restful_Sinatra) — API Sinatra com testes em RSpec e MongoDB.
- [rocklov](https://github.com/AnaCarolinaSantos-qa/rocklov) — projeto de curso com cenários de API e web em Ruby, RSpec e Cucumber.

## Materiais de estudo

- [NinjaWeek](https://github.com/AnaCarolinaSantos-qa/NinjaWeek) — materiais e exercícios de estudos de QA.
- [RobotFrameworkWeek](https://github.com/AnaCarolinaSantos-qa/RobotFrameworkWeek) — materiais e exemplos de Robot Framework.
