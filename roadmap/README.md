# Roadmap de exploração

Os tópicos abaixo são interesses e explorações futuras/em andamento, não projetos concluídos nem competências comprovadas por entregas neste repositório:

- Avaliação de LLMs aplicada a cenários de Quality Engineering
- RAG e context engineering para apoiar atividades de qualidade
- Sistemas multiagentes com supervisão human-in-the-loop
- Governança de autonomia, limites e trilhas de auditoria
- Exemplos sintéticos de AI-powered Quality Engineering

As entradas só serão marcadas como concluídas quando houver artefato público verificável.
